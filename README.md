## 🚀 Quick Start

### Installation & Setup
```bash
# Clone the repository
git clone https://github.com/rkohli35-cyber/rkohli35-cyber.git
cd rkohli35-cyber

# Make the agent executable
chmod +x cybersecurity_scholar.py

# Run the agent
python3 cybersecurity_scholar.py --help
```

### Basic Usage
```bash
# Get agent information
python3 cybersecurity_scholar.py -c "about"

# Analyze a cybersecurity threat
python3 cybersecurity_scholar.py -c "analyze malware"

# Get policy recommendations
python3 cybersecurity_scholar.py -c "recommend data_protection university"

# Research guidance
python3 cybersecurity_scholar.py -c "research 'IoT security' empirical"

# Start interactive mode
python3 cybersecurity_scholar.py -i
```

### Available Commands
- `analyze <threat_type>` - Analyze cybersecurity threats from academic perspective
- `recommend <policy_domain>` - Get policy recommendations for institutions
- `research <topic>` - Receive guidance on cybersecurity research
- `educate <area>` - Get educational program guidance
- `frameworks` - List available cybersecurity frameworks
- `threats` - List threat categories in knowledge base
- `policies` - List available policy domains
- `help` - Show detailed help information
